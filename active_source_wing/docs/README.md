## الميزات الأساسية

### 🧠 المحركات النفسية المتقدمة
- **Emotional Gravity Engine**: محرك الجاذبية العاطفية
- **Surprise Evolution Engine**: محرك تطور المفاجآت
- **Dual Truth Engine**: محرك الحقيقة المزدوجة
- **Psychological Context Manager**: مدير السياق النفسي

### 💖 النظام العاطفي
- **500+ عبارة عاطفية** متنوعة ومصنفة
- **20 مبدأ إسلامي** مطبق بدقة شرعية
- **نظام التكيف العاطفي** المتقدم
- **التحليل النفسي الذكي**

### 🔐 الأمان والخصوصية
- **تشفير متقدم** (AES-256, HMAC)
- **مصادقة بيومترية** متعددة المستويات
- **حماية البيانات المحلية** بدون خوادم خارجية
- **امتثال شرعي** مدمج في كل خدمة

## البدء السريع

### للمطورين
```bash
# استنساخ المشروع
git clone [repository-url]
cd active_source_wing

# تثبيت التبعيات
flutter pub get

# تشغيل التطبيق
flutter run
```

### للمستخدمين
1. تحميل التطبيق من متجر التطبيقات
2. إنشاء حساب جديد أو تسجيل الدخول
3. ربط الحساب مع الشريك
4. البدء في إنشاء الذكريات والرسائل العاطفية
