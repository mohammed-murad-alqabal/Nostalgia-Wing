# خريطة وثائق مشروع جناح الحنين



> **إعداد فريق تطوير مشروع جناح الحنين**
> 


## الغرض



هذا الملف هو نقطة الدخول الرسمية للوثائق. لا تُعد كثرة الوثائق دليلاً على التنفيذ؛ كل ادعاء عن الحالة الحالية يجب أن يرتبط بالكود أو اختبار أو نتيجة CI حديثة.



## مصادر الحقيقة



| المجال | المصدر الرسمي | قاعدة التحقق |

|---|---|---|

| سلوك التطبيق والتبعيات | `active_source_wing/lib/` و`active_source_wing/pubspec.yaml` | لا تُقبل وثيقة تخالف الكود أو التبعيات الحالية |

| جودة السلوك | `active_source_wing/test/` ونتائج CI | وجود ملف اختبار لا يساوي نجاحه |

| الحالة الحالية | [`current/`](current) | يجب أن تحمل `Status: Current` و`Verified commit` |

| الميزات المستقبلية | [`proposed/`](proposed) و`.kiro/specs/` | لا تُعرض كميزات منفذة قبل اكتمال التتبع |

| القرارات الهندسية | [`decisions/`](decisions) | القرار المقبول هو المرجع، والبديل يحمل `Superseded` |

| الإرشادات | [`guides/`](guides) | إرشادات قابلة للتنفيذ ومراجعة دورية |

| التاريخ | [`archive/`](archive) | غير صالح كمصدر للحالة الحالية |



## حالات الوثائق



تستخدم الوثائق الحالات التالية: `Current` للحالة المثبتة، `Proposed` للتصميم غير المنفذ، `Partial` للتنفيذ الجزئي، `Deprecated` لما لم يعد موصى به، و`Archived` للتاريخ. لا يجوز استخدام `Active` وحدها دون تحديد ما إذا كان المقصود تنفيذياً أم تحريرياً.



## ترتيب القراءة



يبدأ المطور بـ [`current/system-status.md`](current/system-status.md)، ثم [`current/architecture.md`](current/architecture.md)، ثم المواصفة أو الدليل المرتبط بالتغيير. عند اتخاذ قرار معماري، يجب إنشاء ADR في `decisions/` وربطه بمسار الكود والاختبارات.



## سياسة التحديث



أي وثيقة Current يجب أن تتضمن `Status` و`Owner` و`Authority` و`Last verified` و`Verified commit` و`Related code` و`Related tests`. عند استبدال وثيقة، تُنقل النسخة القديمة إلى `archive/` أو تُوسم `Superseded` مع رابط النسخة البديلة، ولا تُحذف المعلومة التاريخية الفريدة.



## تحقق آلي



يشغّل الأمر التالي من جذر المستودع للتحقق من الرؤوس الإلزامية ومنع الوثائق المؤرشفة من الادعاء بأنها Current:



```bash

python3 scripts/verify_documentation_governance.py

```
