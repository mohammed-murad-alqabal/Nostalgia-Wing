# Archived nested GitHub workflow definitions

These workflow definitions were originally stored under `active_source_wing/.github/workflows/`. GitHub Actions only discovers workflow files from the repository-root `.github/workflows/` directory, so these files were not active in this repository.

They are preserved here as historical automation reference. They must not be copied back into `.github/workflows/` automatically. Before any individual workflow is reintroduced, its owner must review its trigger, permissions, third-party actions, write behavior, and overlap with the active root workflows.

The active CI/CD workflows are maintained exclusively in the repository-root `.github/workflows/` directory.
